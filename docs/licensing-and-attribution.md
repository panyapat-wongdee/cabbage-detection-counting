This repository uses a multi-license policy. The repository source, IEEE
publication, external dataset, upstream pretrained assets, and third-party
frameworks each retain their own applicable terms. This document describes
the intended release boundary and is not legal advice.

## Repository source

The revised source code and materials explicitly identified as repository work
are released under Apache License 2.0. The grant is stated in the root
[`LICENSE`](../LICENSE) and is narrowed by [`NOTICE`](../NOTICE).

Apache-2.0 does not apply to the IEEE publication, the external dataset or its
publication, third-party dependencies, pretrained weights, or an
Ultralytics-derived model unless a separate rightsholder grant says otherwise.

## External dataset

The dataset article is *An instance segmentation dataset of cabbages over the
whole growing season for UAV imagery*, Data in Brief, 2024, DOI
[`10.1016/j.dib.2024.110699`](https://doi.org/10.1016/j.dib.2024.110699).

The downloadable data record is *An annotated image dataset of cabbages for
instance segmentation*, Mendeley Data Version 2, DOI
[`10.17632/5cp2dyjczk.2`](https://doi.org/10.17632/5cp2dyjczk.2), under [CC BY
4.0](https://creativecommons.org/licenses/by/4.0/legalcode). The data and
dataset-paper PDF are not included in Git. Users who download or adapt the
data must preserve attribution, link the license, and indicate changes as
required by CC BY 4.0. The repository does not claim ownership of the images
or annotations.

## Pretrained weights and notices

Pretrained weights are not committed or redistributed by this repository.
Users must obtain the exact upstream artifact from its official source and
review its current terms. The complete registry is
[`weights/provenance.yaml`](../weights/provenance.yaml).

The five torchvision records use COCO-trained `COCO_V1` checkpoints and
retain the [torchvision BSD-3-Clause text](../LICENSES/BSD-3-Clause-torchvision.txt)
and torchvision's pretrained-model disclaimer. COCO image records can carry
per-image licenses, so the BSD software license must not be presented as a
blanket license for COCO images or every model artifact.

The five Ultralytics records use the official YOLO/RT-DETR assets documented by
Ultralytics. Their default trained-model terms are `AGPL-3.0-only`; the
[AGPL text](../LICENSES/AGPL-3.0-only.txt) is retained for release bundles.
The original Baidu RT-DETR architecture repository is separately attributed
as Apache-2.0, but that does not replace the effective terms of an
Ultralytics-provided checkpoint or integration.

## Fine-tuned outputs

Fine-tuned torchvision weights may be released externally under Apache-2.0
only for the authors' releasable contribution, with all upstream notices,
COCO provenance, dataset attribution, and any other applicable terms bundled
alongside the artifact. Fine-tuned Ultralytics weights are released externally
under `AGPL-3.0-only` unless an applicable written Enterprise agreement grants
different terms; corresponding source must be provided as required.

SSDLite is released like the other nine models, under the same terms as the
other torchvision-derived checkpoints. Its `study_scope` remains
`supplementary_unreported`: it is not one of the architectures in the cited
study and has no published-paper metric in this repository. Any comparison
between SSDLite and another model must cite this repository's own verified run
artifacts and must not be presented as a published finding.

The fine-tuned licence boundary was confirmed on 2026-09-24 against the
upstream statements it rests on. torchvision's pre-trained model notice says
its models "may have their own licenses or terms and conditions derived from
the dataset used for training", which is why the torchvision archives license
only the authors' contribution under Apache-2.0 and state that the torchvision
BSD-3-Clause notice and MS COCO provenance are retained and that COCO image
licences are not relicensed. Each torchvision archive bundles the full text of
[`LICENSES/BSD-3-Clause-torchvision.txt`](../LICENSES/BSD-3-Clause-torchvision.txt)
under `notices/`, beside the MS COCO and dataset notices; the first upload of
the v1.0.0 assets referenced that text without including it and was replaced
on 2026-09-24 before the repository was made public. Ultralytics states that models trained
with its code fall under AGPL-3.0 by default, with corresponding source
required; every Ultralytics archive names this repository at the run's commit
and the upstream Ultralytics source.

Every external checkpoint release must include the metadata and checksum
sidecar contract documented in [`weights/README.md`](../weights/README.md).
