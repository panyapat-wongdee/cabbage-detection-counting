# External cabbage dataset attribution

Training data: *An instance segmentation dataset of cabbages over the whole
growing season for UAV imagery*.

- Data record DOI: https://doi.org/10.17632/5cp2dyjczk.2
- Dataset article DOI: https://doi.org/10.1016/j.dib.2024.110699
- Data record license: CC BY 4.0

The dataset is external to this repository and is not included in checkpoint
release assets. Users must obtain it from the official source, preserve this
attribution and license link, and indicate changes as required by CC BY 4.0.
